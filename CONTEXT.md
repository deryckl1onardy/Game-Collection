# Shelf

A personal site that presents a digital game library as physical objects — box, cover art, disc, manual. Not a storefront, not a launcher. Its purpose is backlog psychology: reframing an unplayed game as *unopened* rather than neglected.

## Language

### Shelf state

**Unopened**:
A game with zero recorded playtime. Rendered with shrink wrap still on.
_Avoid_: Unplayed, new, untouched

**Unfinished**:
A game with recorded playtime, no `finished` flag set.
_Avoid_: In progress, started, abandoned

**Finished**:
A game the owner has explicitly flagged as done. Always a manual toggle — never inferred.
_Avoid_: Completed, 100%, beaten

**Wrap**:
The shrink wrap rendered over an unopened case. Comes off when recorded playtime rises above zero — whether that playtime arrived from sync or was entered by hand for a manually-tracked game. Never removed by a gesture in the app. Its removal is a record of real play, not an action the interface offers.
_Avoid_: Plastic, seal, film

**Achievement percentage**:
A *signal* that may nudge a game toward "probably finished, confirm?" — never the source of truth for Finished. Many games gate 100% behind multiplayer or collectible grinding, and many ship with no achievements at all.

### Objects

**Case**:
The 3D object representing one game — back shell, spine, hinged front shell, and optional inserts.

**Insert**:
An optional component inside a case (disc, manual). Optional by design so a game with only cover art still renders as an intentional object rather than a broken one. See asset tiers in the project brief.

**Library card**:
The stamped date card on the manual showing session history. Generated by diffing playtime between syncs. The diegetic alternative to a playtime chart.

**Session**:
One recorded increase in playtime between two syncs. The unit the library card stamps.
_Avoid_: Play session, playthrough
